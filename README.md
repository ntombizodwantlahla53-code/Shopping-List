## Project Description
```
This is a responsive Shopping List Application built using React and TypeScript. The application includes user authentication with login and registration pages, protected and public routes for secure navigation, a user profile management page and a dynamic dashboard where users can manage, search and organize their shopping items. It features a modular architecture with CSS Modules for styling, multi-page routing via React Router DOM, and state management powered by Redux.
```

## Key Features
```
User Authentication & Authorization:Secure login and registration flows backed by Redux state management.
Protected Routes:Ensures private pages are only accessible to authenticated users.
Interactive Dashboard: Add, view, search and manage items in your personalized shopping list.
Profile Management: Dedicated view for managing user account details
Styling: Clean, UI components designed using CSS Modules.
```
